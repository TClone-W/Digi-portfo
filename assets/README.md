# Hướng dẫn tải ảnh thực hành của bạn lên dự án

Chào Trung! Do chính sách bảo mật và hạn chế lưu động của môi trường phát sinh, các tệp ảnh bạn tải lên ở khung hội thoại chưa được lưu trực tiếp vào ổ đĩa dự án.

Ứng dụng của bạn đã được cấu hình sẵn sàng để sử dụng ảnh cục bộ từ chính thư mục này thay vì dùng ảnh trên mạng hay ảnh Unsplash ngẫu nhiên.

### Cách thực hiện rất đơn giản:
Bạn hãy chụp lại màn hình 12 bước thực hành của riêng mình (hoặc dùng các file hình ảnh bạn đã chuẩn bị) và tải trực tiếp các tệp tin này vào thư mục `/public/assets/` trên thanh công cụ File Explorer (bên trái màn hình mã nguồn) với tên chính xác như danh sách dưới đây:

| Tên File | Mô tả Bước thực hành tương ứng |
| :--- | :--- |
| **`step1.png`** | Mở File Explorer (Windows + E) |
| **`step2.png`** | Truy cập ổ đĩa hoặc thư mục Documents |
| **`step3.png`** | Tạo thư mục mới `ThucHanh_NguyenDucTrung` |
| **`step4.png`** | Vào thư mục `ThucHanh_NguyenDucTrung` vừa tạo |
| **`step5.png`** | Tạo tệp tin văn bản `GhiChu.txt` |
| **`step6.png`** | Đổi tên tệp tin thành `GhiChuQuanTrong.txt` |
| **`step7.png`** | Tạo thư mục con `TaiLieu` |
| **`step8.png`** | Sao chép tệp tin `GhiChuQuanTrong.txt` vào thư mục `TaiLieu` (Copy & Paste) |
| **`step9.png`** | Di chuyển tệp tin `DiChuyen.txt` vào thư mục `TaiLieu` (Cut & Paste) |
| **`step10.png`** | Xóa tệp tin `GhiChuQuanTrong.txt` vào Thùng rác (Recycle Bin) |
| **`step11.png`** | Xóa vĩnh viễn tệp tin `DiChuyen.txt` bằng Shift + Delete |
| **`step12.png`** | Khôi phục tệp `GhiChuQuanTrong.txt` từ Recycle Bin về vị trí ban đầu |

> **Lưu ý:** Vui lòng giữ đúng định dạng và viết thường hoàn toàn tên tệp (ví dụ: `step1.png`, `step2.png`...) để hệ thống tải chính xác. Ngay sau khi bạn tải tệp vào thư mục này, trang web báo cáo thực hành sẽ tự động cập nhật hiển thị hình ảnh minh chứng thực tế của riêng bạn một cách sống động!
